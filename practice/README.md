## How to use them
1. Take the **Diagnostic** first, without notes.
2. Work through the domain set for each domain in the order of the [study plan](../study-plan.md). Mark your answers with the *Quick answer key* at the bottom of each set, then read the explanations for every question you got wrong.
3. Record your scores in [../progress.md](../progress.md). Re-take any set where you scored under 80% a week later.
4. For a mock-exam feel, mix questions across sets in the exam weighting (about 16 from D1, 12 each from D3 and D4, 11 from D2, and 9 from D5, totalling 60) and allow 120 minutes.
